Admin app (fastui_admin.base)#

Admin application, mounting and routing.

Core admin class for FastUI Admin.

Warning

FastUI Admin does NOT provide authentication, authorization, or CSRF protection. All admin endpoints are publicly accessible by default. Mutating endpoints (create/edit/delete) accept JSON POST without CSRF tokens. FastUI’s fetch-based forms rely on browser same-origin policy, but XSS on the same domain can bypass this. You MUST add your own authentication middleware and consider CSRF protection before deploying to production.

class fastui_admin.base.BaseAdmin(app, engine=None, session_maker=None, title='Admin', base_url='/admin', route_name='admin', logo_url=None, index_view=None, *, debug=False)[source]#

Bases: object

Base class for implementing Admin interface.

Warning

This admin interface has NO built-in authentication. All CRUD endpoints are publicly accessible. Add authentication middleware before deploying to production.

Example

from fastapi import FastAPI
from sqlalchemy.ext.asyncio import create_async_engine

from fastui_admin import BaseAdmin, BaseModelView

app = FastAPI()
engine = create_async_engine("sqlite+aiosqlite:///./db.sqlite")


class UserAdmin(BaseModelView, model=User):
    name = "Users"
    column_list = ["id", "username", "email"]


admin = BaseAdmin(app, engine, title="My Admin")
admin.add_view(UserAdmin)
admin.mount()

Initialize the admin interface.

Parameters:

  • engine¶ – Async SQLAlchemy engine. Sync engines are not supported.

  • session_maker¶ – Optional async session maker. If not provided, created from engine.

  • base_url¶ – Base URL path for admin (default: “/admin”).

  • route_name¶ – Name for the mounted admin route.

class fastui_admin.utils.ViewProtocol(*args, **kwargs)[source]#

Bases: Protocol

Structural interface for admin views.

Lets views and layout reference registered views without importing fastui_admin.base (which would close an import cycle: base already imports both modules). BaseView satisfies this structurally.

name/is_visible are ClassVar (not read-only properties) because views declare them as class variables, and checkers do not accept a ClassVar as the implementation of a read-only property member.
